MeshCore Hotspot-OTA Flasher

Flash a Heltec V4 board straight from your browser over USB.

Unofficial, community tooling for HeyVern/meshcore-hotspot-ota, distinct from MeshCore's own official flasher. Requires a Chromium-based browser (Chrome, Edge, Opera) with Web Serial support.

Serial Console

Talk directly to a running device's CLI over USB -- independent of the flashing wizard. Useful for commands like set ota.wifi or get ota.active without a separate serial terminal app.
