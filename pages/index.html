What makes this firmware different

  • Off-site Firmware Updates One command over the mesh. The node powers its hotspot, joins WiFi, fetches the firmware, verifies it, installs it, and comes back. About a minute.
  • Recovery Rollback New firmware runs on probation. If it fails during startup, the node reverts to the previous image and reboots itself.
  • Settings Stay Current Important settings for your area arrive over the mesh. No more hunting forums and pages trying to figure what setting to change today.
  • Test Settings With Recovery Applys values for a set number of seconds and puts it back unless you confirm it. For the settings that can quietly take a node off the mesh.
  • Brownout Protections A repeater leaves service before the danger zone and sleeps, then returns on its own once the battery has recovered to safe levels. Prevents stranding a node that needs local reset.
  • Enhanced Clock Accuracy Fixes some MeshCore clock drift issues, and opportunistically syncs a node's clock to atomic clocks when available.

MeshCore: stock vs Enhanced+

Stock MeshCore is great, but updates can be a pain. Its start ota turns the node into an access point and waits for a person standing nearby to upload a file. These builds add a second path over an existing WiFi or cell hotspot, with remote power control for the hotspot itself, driven by ordinary CLI commands that travel over LoRa like everything else in the mesh.

Situation Stock MeshCore MeshCore Enhanced+
Updating a remote node Take a trip Send a command over the mesh
A bad firmware image Node halts and stays down Recovers itself and reboots
Region lists change Read up and reconfigure each node Published over the mesh, applied on arrival
Trying a risky setting Drive back out to undo it Reverts on a timer unless you keep it
A battery running flat Browns out and resets in a loop Leaves service, returns once charged

Advanced configuration

The configurator exposes every internal setting, names a repeater, sets its region transport scopes, and pushes the lot over USB. Boards running MeshCore Enhanced+ expose more settings than stock does, including the sync overlay a repeater picks up over the air. The tool assumes familiarity with how the mesh is configured (a wrong value can quietly take a repeater off the air). This is not the tool for a first-time user, but for someone who knows MeshCore's internals and likes turning knobs.
